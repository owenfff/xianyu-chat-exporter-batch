# 闲鱼聊天记录批量导出

🌐 [English](./README.md) | [中文](./README_zh.md)

一个在浏览器本地运行的 Chrome 扩展，用来把闲鱼聊天记录整理并保存到电脑。除了导出当前聊天，也可以按会话批量归档，适合需要长期留存交易沟通记录的场景。

## 功能

- 扫描当前页面中的闲鱼会话列表，自由选择要导出的会话
- 自动打开会话并向上加载历史消息，兼容聊天区域的虚拟列表
- 支持文字、图片、视频和引用消息
- 图片和视频尽量下载为本地文件，和聊天 HTML 一起打包
- 支持暂停、继续、停止，以及关闭弹窗后的进度恢复
- 单聊导出保留 HTML 和 Markdown 两种格式
- 媒体下载失败不会中断整个任务，原始地址和失败原因会写入清单

## 安装

1. 下载或克隆本仓库
2. 打开 Chrome 的 `chrome://extensions/`
3. 开启右上角的「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择本项目文件夹

## 使用

### 批量导出闲鱼会话

1. 打开 [闲鱼网页版](https://www.goofish.com/) 并确认已经登录
2. 点击浏览器工具栏中的扩展图标
3. 切换到「批量导出」页签，点击「扫描会话列表」
4. 默认会全选扫描到的会话，可以取消不需要的项目
5. 点击「开始批量导出」；任务会逐个打开会话并采集历史消息
6. 任务完成后点击「导出 ZIP」保存归档

运行期间可以关闭扩展弹窗，重新打开后会继续显示任务进度。遇到验证码、访问限制或页面状态异常时，任务会暂停，处理页面后可以继续。

### 导出当前聊天

在「当前聊天」页签中，可以查看当前页面已经采集到的消息，勾选需要的内容后导出 HTML 或 Markdown。

## ZIP 文件结构

```text
闲鱼聊天备份.zip
├─ manifest.json
├─ conversations/
│  ├─ 会话一.html
│  └─ 会话二.html
├─ raw/
│  ├─ 会话一.json
│  └─ 会话二.json
└─ media/
   ├─ 会话一_001.jpg
   └─ 会话二_001.mp4
```

HTML、原始 JSON 和媒体文件都会按会话整理。重复昵称会自动生成不重复的文件名；如果归档过大，扩展会尝试按会话拆分 ZIP。

## 工作方式与边界

- 只通过当前登录页面读取内容，不调用闲鱼内部分页接口
- 同一时间只处理一个会话，不并发打开多个聊天
- 不读取 Cookie，不向第三方上传聊天内容
- 首版不保证语音、文件、贴纸和系统消息
- 图片或视频链接可能过期；失败时仍保留消息和原始 URL
- 默认只导出当前页面能够扫描到的会话

## 支持平台

- 闲鱼网页版：`xianyu.com`、`goofish.com`
- Fiverr：保留当前聊天的单聊导出能力
